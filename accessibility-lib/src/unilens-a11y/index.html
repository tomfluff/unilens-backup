UniLens アクセシビリティ UMD デモ

右上の 表示調整 ボタンから全機能を試せます。

埋め込み例

<script src="accessibility.js"></script>
      <script>Accessibility.init()</script>

パネルの言語は <html lang> とブラウザの設定から自動で決まります。 既定を明示したいときは init({ lang: 'en' }) を渡してください。 利用者がパネル内で選んだ言語のほうが常に優先されます。

テキストサンプル

この段落は表示調整の効果を確認するためのサンプルです。文字サイズや色、コントラストの変化を観察してください。

11px の注記テキスト — 小さな文字底上げ・本文拡大の対象になりやすいサンプルです。

サンプルリンク — リンク色もテーマに連動します。

カラーパッチ

赤 緑 青 — 彩度調整の確認用

含まれる機能

  • カラーモード / 彩度 / コントラスト
  • ページ全体の文字（サイズ・UDフォント・行間）
  • 本文のみ拡大（見出し除外・3段階）
  • 16px未満の小さな文字底上げ（3段階）
  • 選択文字サイズ（100% / 150% / 200%）
  • 自動文字サイズ（分析・適用）

設定は localStorage に保存され、リロード後も復元されます。
