'''かがみ'''、'''鏡'''（かがみ）は、以下のものを指す。

== 地名 ==
* [[kagami-river|鏡川]] - みのり県最大の河川。春川市でみのり湾に注ぐ
* [[kagami-bridge|鏡橋]] - 春川市中心部の鏡川に架かる道路橋
* [[?鏡町]] - みのり県の町。鏡川の中流域に位置する
* 鏡峡 - 鏡町にある鏡川の峡谷。最寄り駅は鏡線の鏡峡駅。→[[kagami-river|鏡川]]を参照
* 鏡郡 - みのり県の郡（鏡町・月見町）。古代の実野国にも置かれた。→[[minori-prefecture|みのり県]]、[[history-of-harukawa|春川市の歴史]]を参照
* 鏡津（かがみのつ） - 1603年に春川と改称された港町の旧称。→[[history-of-harukawa|春川市の歴史]]を参照

== 寺社 ==
* [[?鏡神社]] - 春川市の神社。鏡川から引き上げられたと伝わる銅鏡を祀る

== 交通 ==
* [[kagami-line|鏡線]] - 春川中央駅と月見温泉駅を結ぶ春川鉄道の路線
* 鏡谷鉄道（かがみだにてつどう） - 1923年の創立から1951年までの[[harukawa-railway|春川鉄道]]の社名
* 鏡峡駅 - 鏡町にある鏡線の駅。鏡峡の最寄り駅。→[[kagami-line|春川鉄道鏡線]]を参照

== 食べ物 ==
* 鏡汁 - 焼いた鮎とユズの皮の澄まし汁。鏡のように澄んだ汁に由来する名。→[[cuisine-of-harukawa#鏡汁|春川の郷土料理]]を参照
* [[?鏡餅]] - 正月に供える、丸い餅を2段に重ねた飾り

== 作品 ==
* 『鏡の川』 - [[michiyo-tono|遠野美千代]]の小説（1956年）。1739年の洪水を描く

== その他 ==
