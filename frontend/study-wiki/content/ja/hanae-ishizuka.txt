'''石塚 花枝'''（いしづか はなえ、1921年〈大正10年〉3月12日 - 2009年〈平成21年〉1月30日）は、日本の陶芸家。[[minori-prefecture|みのり県]][[harukawa|春川市]]出身。[[harukawa-ware|春川焼]]の作家で、[[?河辺秋山]]に師事した。1952年に陶山で霞窯を開き、[[harukawa-castle|春川城]]の藩窯跡から出土した陶片を6年にわたって研究して、1964年に途絶えていた「霞釉」（かすみゆう）を復元した。1985年に重要無形文化財「霞釉陶器」の保持者（人間国宝）に認定された。みのり県出身の女性陶芸家としては初めての認定である<ref name="mpma2011">みのり県立美術館 編（2011）『石塚花枝 寄贈作品展』展覧会図録、4–7頁。</ref>。

== 生い立ち ==
1921年3月12日、春川の北東にあった窯業の村、陶山村（1942年に春川市へ編入）に生まれる。父の石塚源吉は、1736年創業の民窯である谷口窯のろくろ職人であった。幼少期には1931年まで焚かれていた共同登窯「陶山古窯」の最後の窯焚きを見て育ち、後年、窯の煙のにおいが最も古い記憶だと語っている<ref name="ishizuka1975">石塚花枝（1975）『霞 失われた釉の覚書』みのり出版、9–14頁。</ref>。県立春川高等女学校を1938年に卒業した。

== 修業時代 ==
1938年、17歳で、1919年に秋山窯を開いて春川焼の再興に取り組んでいた河辺秋山（1881年 - 1958年）に入門した。秋山が初めて受け入れた女性の弟子であった。最初の2年間は土作りと釉薬の原料の粉砕に従事し、ろくろに向かうことを許されたのは1940年になってからだという{{cn}}。秋山は江戸時代の藩窯の作品を研究しており、その釉の再現に失敗を重ねる師の姿が、石塚が霞釉に関心を抱くきっかけとなった。

1944年から1945年にかけて秋山窯は戦時の燃料統制により操業を停止し、石塚は陶山の工場で磁器製の碍子の製造に従事した。1946年に秋山窯に戻った。

== 霞窯 ==
1952年、陶山に2室の薪の登窯を築いて独立した。窯の名は、いつか取り戻したいと願っていた藩窯の釉にちなんで「霞窯」とした{{efn|窯と釉の名は、みのり湾の[[?霞島]]に由来するものではない。いずれも「かすみ」を意味する霞の字を用いている。}}。同年、第1回の[[harukawa-ware#釜野陶器市|釜野陶器市]]に出品している。1950年代には、主に飴色の灰釉に川筋文を描いた徳利、壺、皿を制作した<ref name="morioka">森岡健二（1997）『春川焼 陶山四百年の歩み』みのり出版、152–171頁。</ref>。

== 霞釉の研究 ==
1958年、1624年から1871年まで春川城二の丸にあった藩窯・鷺舞窯の跡が発掘され、約6,800点の陶片が出土した。御用窯を世襲した大谷家は釉の調合を書き残さなかったため、霞釉の製法は1871年以来失われていた。石塚は陶片の調査の許可を得て、1958年から1964年までの6年間、その釉の再現に取り組んだ。

川俣や一ノ瀬の稲藁の灰、ナラ・マツ・クリなどの木灰、[[kagami-river|鏡川]]流域の砂や岩石を試し、1961年からは[[harukawa-university|春川大学]]の化学者に試料の分析を依頼した。研究ノートには214回の試験焼成が記録されている。1964年10月の最後の試験焼成で、陶片と一致する釉が得られた。稲藁灰、木灰、鏡川の長石を合わせたもので、口縁では陶山土の鉄分が褐色の帯となって透けるよう薄く掛けられていた<ref name="ishizuka1975"/>。

石塚は大谷家とは異なり、その成果を公開した。1970年に基本調合を陶山窯業協同組合に提供し、1970年代末には陶山のほとんどの窯元がその変法を用いるようになり、霞釉は春川焼全体の特色となった。

== 評価 ==
1966年の茶碗「朝靄」は、広く展示された最初の霞釉作品である。1967年には大壺「川筋」が日本伝統工芸展で受賞した。1972年にみのり県文化賞を受け、1979年の春川焼の伝統的工芸品指定にあたっても、その仕事が大きな根拠となった<ref name="nippo1985">「石塚花枝さん人間国宝に」『春川日報』1985年7月20日、1面。</ref>。

1985年、国は石塚を重要無形文化財「霞釉陶器」の保持者に認定した{{efn|「人間国宝」は重要無形文化財の保持者として国が認定した人物の通称である。認定は作品群ではなく特定の技法に対して行われ、石塚の場合は霞釉陶器であった。}}。みのり県出身の女性陶芸家としては初めての認定であった。1994年には春川市名誉市民となった<ref name="koho1994">春川市（1994）「石塚花枝さんに名誉市民の称号」『広報はるかわ』1994年6月号、2頁。</ref>。

== 指導と弟子 ==
石塚は十数人の弟子を育てた。最もよく知られるのは[[?水原蓮]]（1956年 - ）で、1975年から1984年まで石塚のもとで修業し、2009年から霞窯の当主を務めている。水原はさらに高野美緒（1988年 - 、2010年 - 2017年修業）を育て、河辺秋山に始まる系譜は4代に及んでいる。石塚は1981年から1991年まで春川大学陶磁研究センターの客員教授を務め、1988年に始まった姉妹都市ケルブリッジ（英国）との陶芸家交流にも初期から関わった<ref name="mizuhara2014">水原蓮（2014）「師のノート」『季刊陶芸』第112号、30–37頁。</ref>。

== 作風 ==
石塚の作品は抑制がきいている。茶碗は輪郭がわずかに歪み、器壁は薄く、高台は低い。霞釉は口縁で薄く掛け、鉄褐色の帯を引き出す。柚子肌は控えめに用い、むしろ滑らかで霞がかった釉肌を好んだ。大壺では、釉の下に刷毛で描いたゆるやかな川筋文を霞釉と組み合わせている。石塚は霞釉を「発明」ではなく「発見」したものと語っている。

{{quote|釉は失われていたのではありません。川の砂と田んぼの中で待っていたのです。私は正しい順番で尋ねればよかっただけです。|石塚花枝（『春川日報』のインタビュー、1985年）}}

== 死去と遺産 ==
2009年1月30日、春川市で死去した。87歳没<ref name="nippo2009">「陶芸家・石塚花枝さん死去 87歳」『春川日報』2009年1月31日、1面。</ref>。2010年、遺族は作品312点と釉の研究ノートを[[minori-prefectural-museum-of-art|みのり県立美術館]]に寄贈した。同館は2011年に石塚の作品を専門に展示する室を設け、2021年には生誕100年展を開いた。研究ノートは春川焼の技法に関する最も重要な資料とされている。
