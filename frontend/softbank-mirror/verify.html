SoftBank IR ミラー — 検証

make bundle でコピーされた accessibility.js / unilens.js / quiz.js を使います。

main 取り込み後の確認項目

  • 表示調整 — 右上の ♿ パネル（Accessibility.init()）。
  • 設定パネル — 左下のギア。変更内容が分かる UI（main の設定パネル）。
  • チャット — Alt + クリック（make serve-backend、ポート 5000）。
  • 共同デザイン用プリセット — URL に ?unilens-preset=initial、またはファシリテータ Ctrl+Alt+Shift+B。
  • 研究ログ — ?pid=P01&session=1（バックエンド起動時）。
  • アンケート — 左上の「アンケート」ボタン（UniLensQuiz.init()、質問は quiz.json の UniLens PoC アンケート 4 問。上部の「日本語 / English」で言語を切り替え。正誤は表示しない）。回答は backend/quiz-logs/softbank-mirror.jsonl、取得は GET /api/quiz/softbank-mirror/results。

他の検証用フロント（make serve-all または make serve-frontend …）：

  • 簡易デモ — localhost:8001（dev-demo）
  • 採用 disability ミラー — localhost:8002/recruit/disability/
  • 研究用モック — ポート 8031–8036（frontend/STUDY-SITES.md）
