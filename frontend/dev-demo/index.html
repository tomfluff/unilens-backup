Verification checklist (main)

This page loads the latest accessibility.js and unilens.js copied by make bundle.

  • Display adjustment — top-right ♿ panel (Accessibility.init()).
  • Settings panel — gear at bottom-left; shows what each control changes.
  • Chat — Alt + click (needs make serve-backend on port 5000).
  • Co-design preset — add ?unilens-preset=initial (or facilitator Ctrl+Alt+Shift+B).
  • Study log — ?pid=P01&session=1 with the backend running.
  • Survey (quiz-lib) — the top-left Survey button opens the survey page on the backend (/survey?quiz=unilens-poc, with this page's pid / session and language).
