採用 disability ミラー — 検証

make bundle でコピーされた accessibility.js / unilens.js / quiz.js を使います。

main 取り込み後の確認項目

  • 表示調整 — 右上の ♿ パネル（本番 DOM 上で約 1,700 ノードのパフォーマンス確認向き）。
  • 高コントラストの適用範囲（3 パターン） — 表示調整パネルの「Lab」タブ →「高コントラスト時の文字背景と文字の色」→「高コントラストを当てる範囲」で 本文のみ／本文＋部品（既定）／すべて を切り替え。カラーモードが「高コントラスト」のとき有効。
  • 設定パネル — 左下のギア（main の設定パネル）。
  • チャット — Alt + クリック（make serve-backend、ポート 5000）。
  • 共同デザイン用プリセット — ?unilens-preset=initial または Ctrl+Alt+Shift+B。
  • 研究ログ — ?pid=P01&session=1（バックエンド起動時）。
  • アンケート — 左上の緑の「アンケート」ボタンを押すと、アンケートサーバーのページ（http://127.0.0.1:5100/survey?quiz=unilens-poc、make serve-survey）が新しいタブで開きます。このページの pid / session を引き継ぎます。

他の検証用フロント：

  • SoftBank IR ミラー — localhost:8000/verify.html
  • 簡易デモ — localhost:8001
  • 研究用モック — ポート 8031–8036
